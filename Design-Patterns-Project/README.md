# Design Patterns Implementation

This project contains the five HTML/CSS/JavaScript demonstrations from the supplied Design Patterns document.

## Applications

### Singleton
- `Singleton/logger.html` — Singleton Logger
- `Singleton/university.html` — University Database Manager
- `Singleton/library.html` — Library Management System

### Factory Method
- `Factory-Method/vehicle-rental.html` — Vehicle Rental Management System (Car, Bike, Bus)

### Behavioral Patterns
- `Behavioral-Patterns/smartfood.html` — SmartFood using Observer, Strategy and Command

## How to run
Open any `.html` file in a web browser, or open the project folder in Visual Studio Code and use the Live Server extension.

## Notes
These are educational browser demonstrations. The university database manager simulates SQL queries; it does not connect to a real database. The library and SmartFood applications keep demo data in memory, so data resets when the page is reloaded.
